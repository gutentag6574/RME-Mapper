# Документация RME Mapper

Папка `docs/` содержит рабочую документацию проекта.

## Файлы

- `TZ.md` — техническое задание на программу.
- `CRS_INFO.md` — сведения о системах координат, проекциях и параметрах преобразования.
- `MAPS_INFO.md` — реестр используемых карт и их геопривязки.
- `TEST_POINTS.md` — контрольные точки для сравнения с QGIS.
- `DATA_FORMATS.md` — форматы ручного ввода и пакетного импорта координат.
- `DEVELOPMENT_PLAN.md` — очередность разработки программы.
- `ACCEPTANCE_CRITERIA.md` — критерии приемки и проверки функций.
- `OPEN_QUESTIONS.md` — вопросы, которые нужно уточнить до или во время разработки.

## Правило ведения документации

После каждого значимого изменения программы обновлять соответствующий файл в `docs/`.

Все неизвестные параметры не придумывать. Помечать их как `УТОЧНИТЬ` и заполнять после проверки в QGIS или по исходным материалам.

Исходные файлы карт и литературы не изменять. Для обработанных версий использовать отдельные папки проекта.
