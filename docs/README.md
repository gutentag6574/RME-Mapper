# Документация GeoPoint Mapper

Папка `docs/` содержит актуальную техническую документацию проекта.

## Основные документы

- [CURRENT_PLAN.md](CURRENT_PLAN.md) — **Единый источник истины**: текущий статус (Этапы 1–17), план будущих этапов (18–27) и архитектурные правила.
- [GPMAP_FORMAT.md](GPMAP_FORMAT.md) — Спецификация формата проектов `*.gpmap` (схемы v1 и v2).
- [GEOTIFF_SUPPORT.md](GEOTIFF_SUPPORT.md) — Архитектура растрового бэкенда GeoTIFF и динамического окна обзора.
- [IMAGE_EXPORT.md](IMAGE_EXPORT.md) — Документация модуля экспорта карт в PNG/JPEG с графическими декорациями.
- [IMPORT_FORMATS.md](IMPORT_FORMATS.md) — Спецификация импорта координат (DD/DMS/XY), кодировок и разделителей (XLSX, CSV, TXT).
- [OBJECT_MODEL.md](OBJECT_MODEL.md) — Расширенная модель пространственных объектов, стили маркеров и геозон.
- [CRS_INFO.md](CRS_INFO.md) — Сведения о системах координат и правилах геодезических преобразований.
- [LOCALIZATION.md](LOCALIZATION.md) — Архитектура интернационализации (RU/EN).
- [PLATFORM_COMPATIBILITY.md](PLATFORM_COMPATIBILITY.md) — Требования к платформам и бэкендам.
- [archive/legacy/](archive/legacy/README.md) — Исторический архив устаревшей предварительной документации.
