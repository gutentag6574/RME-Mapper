# GeoPoint Mapper 1.0.1

Дата: 10 ноября 2026 года. Сборка Windows x64.

## Изменения

- Исправлен запуск команды «Геопривязать изображение» и кнопки «Обзор».
- Добавлен импорт World File: PGW/PNGW, JGW/JPGW/JPEGW, TFW/TIFW/TIFFW, WLD.
- Готовая привязка применяется без повторного ввода контрольных точек.
- Система координат читается из соседнего PRJ; при его отсутствии требуется явный выбор CRS.
- Добавлен пункт WGS 84 / UTM zone 39N (EPSG:32639) с подсказкой по координатам в метрах.
- Сохраняется возможность повторно открыть привязку без контрольных точек для редактирования CRS.
- Pillow включён в зависимости установки.
- Устранён конфликт DLL при импорте QtWidgets: посторонняя ICU из окружения сборки больше не включается в пакет.
- Проверка релиза обнаруживает такую несовместимую DLL. Установщик удаляет её остаток при обновлении.
- Исправлена настройка кодировки путей GDAL для запуска из папок с кириллицей.

## Запуск

Установщик: `release/installer/GeoPointMapper-1.0.1-Setup-x64.exe`.

Без установки: распакуйте `release/portable/GeoPointMapper-1.0.1-portable.zip`
в **новую папку** и запустите `GeoPointMapper/GeoPointMapper.exe`.
Сохраняйте всю папку с `_internal`: одного EXE недостаточно.
Распаковка поверх старой сборки может сохранить несовместимые DLL старой версии.

Для PNG с готовой привязкой держите `plan.png`, `plan.pgw` и, при наличии,
`plan.prj` в одной папке. Откройте PNG или PGW через «Открыть карту», проверьте
систему координат и нажмите «Применить».

## Проверка сборки

Проверены запуск автономного EXE без переменных Python и внешних путей PROJ/GDAL,
запуск распакованного Portable из папки с кириллицей и пробелами, наличие Qt/GDAL/PROJ
и ресурсов приложения. Успешно пройдены 135 тестов исходного кода, покрывающих импорт
привязки, вращение и сдвиг на половину пикселя, выбор CRS, работу диалогов,
сохранение проектов и структуру релиза. Контрольные суммы артефактов находятся в
`release/SHA256SUMS.txt`, метаданные — в `release/release_manifest.json`.

Изменение дизайна в эту версию не включено.
