# GeoPoint Mapper 1.1.0 — интерфейс и удобство работы

Изменения перенесены в исходный `D:\RME-Mapper`, ветка `main`, по просьбе
пользователя. Дополнительно исправлены подтверждённые замечания аудита и внедрены
настройки, поиск на карте, WMS, импорт полевых файлов и постоянные измерения:
[подробный отчёт](AUDIT_RESOLUTION.md). Прежние архив и установщик 1.0.1 сохранены.

## Что реализовано

- Вкладки «Слои», «Группы», «Подложки», «Треки» в левой панели.
- Широкая таблица точек снизу. Через меню «Вид → Таблица точек снизу» можно вернуть
  её влево. Режим, высота таблицы и активная вкладка сохраняются.
- Автоматическое скрытие пустой панели свойств. Выбор точки открывает свойства.
  Автоматический режим отключается в меню «Вид»; ручное скрытие панели сохраняется.
- Измерение расстояния, площади и экспорт доступны на основной панели.
- Светлая, тёмная и системная темы с общим оформлением полей, вкладок и диалогов.
- Геопривязка по шагам: CRS → контрольные точки при необходимости → проверка
  охвата и применение. Для готовой привязки шаг контрольных точек пропускается.
  Ошибочные числа подсвечиваются; для непривязанного изображения CRS нужно указать явно.
- Выбор CRS с названием, единицами и избранными системами координат.
- Открытие изображений и World File через меню, перетаскивание и недавние карты.
- «Импорт → Вставить координаты»: таблица из буфера, выбор разделителя, заголовков,
  столбцов X/Y/названия и исходной CRS. Результат проверяется построчно. Импорт
  разрешён после исправления ошибок и отменяется одним действием.
  Ctrl+V действует в таблице точек; Ctrl+Shift+V открывает импорт из меню.
  Перемещение точки перенесено на Ctrl+Alt+M, чтобы сочетания не конфликтовали.
- «Файл → Собрать проект в архив»: текущее состояние проекта, карта, файлы
  привязки и дополнительные подложки сохраняются вместе с относительными путями.
  Исходный проект не изменяется. Распакуйте архив целиком и откройте `project.gpmap`.
- Дополнительные растровые подложки с порядком отображения, видимостью и
  прозрачностью. Настройки сохраняются в проекте и учитываются при экспорте карты.

## Границы текущей реализации

Растры в другой CRS перепроецируются в CRS активной карты через rasterio.
Дополнительные подложки отображаются превью до 4096 пикселей по большей стороне;
экспорт использует полный исходный растр.

Тема меняет оформление приложения; цвета картографических объектов сохраняются.
Отображение основных данных и экспорт не зависят от выбора светлой или тёмной темы.

Обычная сборка 1.1.0 использует рабочий профиль приложения. Ранее выданная
предварительная сборка из `scratch/ux-workspace` остаётся отдельной версией с
профилем `GeoPointMapperUXPreview`.

## Проверки

Новые тесты охватывают переключение панелей, сохранение настроек, свойства при
выборе точки, вставку координат с проверкой и Undo/Redo, избранные CRS,
шаги геопривязки, перенос проекта, порядок и прозрачность подложек, экспорт
цветов и повторное открытие проекта из перенесённого архива.

Логи текущей проверки: `scratch/audit-*.log`; проверки новой функциональности
находятся в `tests/test_audit_fixes.py` и `tests/test_ux_workspace.py`.
