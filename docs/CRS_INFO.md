## 6. План проверки CRS

1. Получить CRS слоя из QGIS.
2. Получить CRS проекта QGIS.
3. Сохранить EPSG либо полный WKT/PROJ.
4. Подготовить не менее 5 контрольных точек.
5. Получить для них эталонные X/Y в QGIS.
6. Реализовать преобразование через `pyproj`.
7. Сравнить X/Y программы с QGIS.
8. Только после совпадения подключать преобразование к интерфейсу.
