# Реестр карт проекта

## Правила

1. Исходный файл карты хранить отдельно от обработанной версии.
2. Исходник не изменять.
3. Для каждой карты фиксировать CRS и источник.
4. Если геопривязка неизвестна — не считать карту готовой для программы.

## Требования к будущему каталогу карт

Для каждой карты планируется отдельная папка:

```text
maps/
  map_id/
    map.tif
    metadata.json
    preview.png
```

Минимальные поля `metadata.json`:

```json
{
  "id": "map_001",
  "name": "Название карты",
  "file": "map.tif",
  "crs": "EPSG:XXXX или WKT/PROJ",
  "year": "",
  "source": "",
  "description": ""
}
```
