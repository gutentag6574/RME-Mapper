# Руководство по поддержке устаревших платформ (Legacy Windows Guide)

**Продукт**: GeoPoint Mapper  
**Версия**: 0.12.0  
**Дата**: 22 сентября 2026 г.  

---

> [!WARNING]
> **Уведомление об окончании жизненного цикла (EOL Warning)**:  
> Операционные системы **Windows 7** (окончание поддержки: 14 января 2020 г.) и **Windows XP** (окончание поддержки: 8 апреля 2014 г.) официально признаны корпорацией Microsoft устаревшими (End of Life). Для них не выпускаются обновления безопасности ядра, сетевого стека и корневых сертификатов. Использование данных систем сопряжено с системными рисками информационной безопасности. GeoPoint Mapper строго придерживается принципа безопасности данных и запрещает использование небезопасных каналов передачи информации и отключение проверки SSL/TLS сертификатов.

## 1. Обзор поддержки операционных систем

### 1.1. Modern Support (Windows 10 / Windows 11)
- **Целевая платформа**: Windows 10 (версии 1809+), Windows 11 (x64).
- **Статус**: **Основная полнофункциональная платформа (Full Feature / Production Ready)**.
- **Стек**: Python 3.12+, PySide6 (Qt 6.6+), PROJ 9+, GDAL/rasterio 1.3+, Shapely 2.0+, pyogrio 0.7+, numpy 1.26+.
- **Возможности**:
  - Высокопроизводительный рендеринг до 100 000 точек в реальном времени с адаптивным LOD;
  - Векторные слои GeoPackage с атрибутивным поиском и границами;
  - Растровые подложки GeoTIFF с чтением окон обзора и перепроецированием;
  - Ручная геопривязка растровых карт по контрольным точкам (аффинное преобразование);
  - Онлайн-карты (OpenStreetMap, CartoDB, Mapbox) с безопасным TLS 1.3 / HTTP/2 и дисковым кэшированием;
  - Полный спектр форматов импорта/экспорта (CSV, XLSX, TXT, GeoJSON, PNG, JPEG).

### 1.2. Windows 7 Support (Windows 7 SP1 x64 / x86)
- **Целевая платформа**: Windows 7 SP1 (с установленными обновлениями KB2999226 UCRT и KB3063858).
- **Статус**: **BUILDABLE / NOT TARGET-TESTED**.
- **Стратегия поддержки**:
  - Сборка на базе **Python 3.8.10** (последняя версия CPython с официальной поддержкой Windows 7);
  - GUI на базе **PyQt5 5.15.10** или **PySide2 5.15.2.1** (Qt 5.15 LTS);
  - Фиксация проверенных версий GIS-библиотек (см. `requirements-win7.txt`).
- **Сетевой стек**: Поддерживает TLS 1.2 / TLS 1.3 при наличии обновленных корневых сертификатов (ISRG Root X1).

### 1.3. Windows XP Status (Windows XP SP3 x86)
- **Целевая платформа**: Windows XP Professional SP3 (32-bit).
- **Статус**: **BLOCKED (Заблокировано)**.
- **Причины блокировки**:
  - CPython завершил поддержку на версии **3.4.4**; синтаксис современного Python (PEP 585/604 аннотации типов, f-строки, `@dataclass`) вызывает фатальные ошибки парсера;
  - Отсутствие поддержки PySide6 / Qt5;
  - Отсутствие безопасного криптографического стека (TLS 1.2/1.3 недоступны, корневые сертификаты просрочены).
  - В соответствии с правилом «Никакого небезопасного TLS» и «One source tree» запуск на XP признан нецелесообразным и заблокирован без фальсификации статуса.

## 2. Архитектура единого дерева исходных кодов (One Source Tree)

Проект **GeoPoint Mapper** категорически отвергает создание дублирующих поддеревьев исходного кода (таких как `src/rme_mapper_legacy` или `legacy_map_canvas.py`). Вся архитектура строится вокруг централизованного слоя обнаружения возможностей:

```
                           +------------------------+
                           |  RuntimeCapabilities   |
                           +-----------+------------+
                                       |
              +------------------------+------------------------+
              |                        |                        |
              v                        v                        v
    +-------------------+    +-------------------+    +-------------------+
    |   BackendFactory  |    | ProjectController |    |    MainWindow     |
    +---------+---------+    +---------+---------+    +---------+---------+
              |                        |                        |
     [GeoPackage / GeoTIFF]     [Safe Open & Save        [Graceful Action
      выбор бэкенда по           Round-Trip Metadata      Disable & Tooltips
      возможностям среды]        Preservation]            for Unsupported]
```

## 3. Зафиксированные версии зависимостей (Pinned Dependency Matrix)

Для Windows 7 сформирован профиль зависимостей `requirements-win7.txt`:

```text
# GeoPoint Mapper — Windows 7 Profile (Python 3.8.10)
# Точные версии для стабильной совместимости с Windows 7 SP1 x64/x86

PyQt5==5.15.10
numpy==1.24.4
shapely==2.0.1
pyproj==3.5.0
openpyxl==3.1.2
Pillow==10.0.0
```

### Обоснование выбора версий:
1. `PyQt5==5.15.10`: Последний стабильный LTS-релиз ветки Qt 5.15 для Python 3.8, обеспечивающий полную совместимость с графической подсистемой Windows 7.
2. `numpy==1.24.4`: Финальный релиз ветки numpy 1.24, поддерживающий Python 3.8. Ветка numpy 1.25+ требует Python >= 3.9.
3. `shapely==2.0.1`: Первая версия Shapely 2.0 с векторизованным C-API, сохранившая официальные бинарные колеса под Python 3.8 Windows x64.
4. `pyproj==3.5.0`: Стабильный релиз, поставляющий встроенную базу данных `proj.db` и совместимый с Python 3.8.
5. `openpyxl==3.1.2`: Чистопитоновый пакет, полностью совместимый с Python 3.8.
6. `Pillow==10.0.0`: Поддерживает базовые форматы растров под Python 3.8.

Для Windows XP файл `requirements-xp.txt` **не создается**, так как платформа официально заблокирована (Правило 35).

## 4. Поведение при недоступности функций (Feature Degradation)

Если определенная функция недоступна в текущей среде:
1. **Онлайн-карты (Online Maps)**:
   - Если сетевой менеджер или валидация TLS недоступны: пункт меню «Онлайн-карты» отключается (`setEnabled(False)`).
   - Пользователю отображается поясняющая всплывающая подсказка: *«Онлайн-карты недоступны: безопасный стек TLS не поддерживается в данной конфигурации»*.
2. **Растровые карты GeoTIFF**:
   - Если бэкенд rasterio/GDAL недоступен: выбор GeoTIFF в диалогах отключается с информативным сообщением.
3. **Отсутствие крашей**:
   - Ни одна отсутствующая опциональная библиотека не приводит к падению приложения при старте (`ImportError`).

## 5. Межплатформенная совместимость проектов (*.gpmap) и Round-Trip

Формат проекта `*.gpmap` является общим и платформонезависимым:
- Использует стандартный **UTF-8 JSON** (v1).
- Хранит относительные пути к локальным файлам карт.

### Сохранение метаданных неподдерживаемых источников (Round-Trip Preservation):
Сценарий:
1. Пользователь в **Modern Build** создает проект с подключенной онлайн-картой (`source_type: "online_xyz"`, `provider_id: "osm_standard"`).
2. Проект открывается на машине **Legacy Build** (где онлайн-карты отключены из соображений TLS).
3. **Поведение**:
   - Приложение НЕ падает;
   - Пользователь видит предупреждение о недоступности онлайн-подложки;
   - Карта открывается с пустым холстом, но **все точки, группы, стили и зоны загружаются корректно**;
   - Пользователь добавляет/редактирует точки и нажимает «Сохранить»;
   - **КРИТИЧНО**: Метаданные онлайн-карты (`online_xyz`) **НЕ удаляются** из файла `*.gpmap`, а сохраняются в секции `map`;
   - Проект повторно открывается в **Modern Build**: онлайн-карта автоматически подключается обратно вместе со всеми новыми точками.

## 6. Безопасность и ограничения сетевого взаимодействия

- **Никаких исключений для TLS**:
  - `verify=False` категорически запрещен;
  - Игнорирование ошибок SSL (`ignoreSslErrors()`) запрещено;
  - Fallback на незащищенный протокол `http://` для сервисов, требующих `https://`, запрещен.
- **Безопасная обработка файлов**:
  - Для сериализации и десериализации используется исключительно стандартный модуль `json`.
  - Модули `pickle`, функции `eval` и `exec` в проекте не используются.
  - Проверка путей на попытки выхода за пределы директории (Path Traversal Protection) активна.

---

## 7. Ограничения 32-битной архитектуры (RAM Ceiling)

Для 32-битных сред (x86):
- Процесс ограничен адресным пространством **2 ГБ RAM**.
- Рекомендуемый безопасный предел количества точек для x86: **25 000 точек** (в отличие от 100 000 точек на Modern x64).
- При превышении объема памяти приложение гарантирует целостность файла проекта благодаря атомарной записи через временные файлы (`*.tmp_...`) с последующим переименованием (`os.replace`).

## 8. Методика сборки тестового бандла Windows 7

Сборка тестового дистрибутива под Windows 7 должна производиться в среде Windows 7 SP1 x64/x86 или на сборочном сервере с Python 3.8.10:
```cmd
REM Установка изолированного окружения
py -3.8 -m venv .venv_win7
.venv_win7\Scripts\activate

REM Установка зафиксированных зависимостей
pip install -r requirements-win7.txt
pip install pyinstaller==5.13.2

REM Тестовая сборка папки приложения
pyinstaller --noconfirm --onedir --windowed --name "GeoPointMapper_Win7" src/rme_mapper/main.py
```
*Примечание: Финальная релизная упаковка (инсталлятор, подпись, portable) запланирована на Этап 26.*
