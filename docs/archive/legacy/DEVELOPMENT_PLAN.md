# План разработки RME Mapper

## Главное правило

Разработка идет маленькими проверяемыми этапами.

Нельзя просить ИИ реализовать все ТЗ целиком одним запросом.

После каждого работающего этапа:

1. проверить приложение;
2. запустить тесты;
3. сделать Git commit;
4. обновить документацию;
5. только после этого переходить дальше.

---

## Этап 0 — исходные материалы

Статус: `В РАБОТЕ`

Нужно получить:

- одну тестовую карту;
- CRS слоя карты;
- CRS проекта QGIS;
- EPSG/WKT/PROJ;
- 5+ контрольных точек;
- эталонные X/Y из QGIS;
- скриншоты точек;
- простой XLSX;
- DMS XLSX;
- ошибочный XLSX;
- материалы по зонам;
- материалы Османовой/Животовского.

Критерий завершения:

есть достаточно данных, чтобы проверить одну координату в QGIS и в будущей программе.
