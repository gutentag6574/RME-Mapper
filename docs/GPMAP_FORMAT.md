# Спецификация формата проекта GeoPoint Mapper (*.gpmap)

## 1. Назначение и принципы

Файл проекта **`*.gpmap`** является официальным кроссплатформенным форматом хранения рабочего состояния приложения **GeoPoint Mapper**.

### Ключевые требования к формату:
1. **Текстовый формат**: Стандартный **UTF-8 JSON** с отступами (2 пробела) и читаемыми Unicode-символами (`ensure_ascii=False`).
2. **Кроссплатформенность**: Полная независимость от платформы (Windows 10/11, Windows 7, Windows XP, Linux, macOS).
3. **Изоляция от GUI-фреймворков**: Формат **НЕ содержит** типов данных, специфичных для Qt, PySide или любых других оконных библиотек (`QColor`, `QPointF`, `QPainterPath`, `QGraphicsItem`).
4. **Независимость путей**: Хранение относительных путей к картам (`relative_path`), разрешаемых относительно директории расположения файла проекта или рабочего корня. Полное отсутствие жестких привязок к буквам дисков (`C:\`, `D:\`) или специфичным системным папкам.
5. **Разделение версий**: Версия схемы формата проекта (`version: 1`) **отделена** от версии приложения (`APP_VERSION: "0.12.0"`). Изменение версии программы не ломает совместимость схемы проекта.
6. **Обратная совместимость**: Приложение сохраняет полную поддержку чтения устаревших файлов проектов ранних этапов (`*.rmeproject`).

## 2. Схема структуры данных (JSON Schema)

```json

  "format": "GeoPoint Mapper Project",
  "version": 1,
  "map": {
    "map_id": "test_map_mari_el",
    "relative_path": "maps/test_map/mari_el.gpkg",
    "name": "Республика Марий Эл",
    "source_type": "geopackage",
    "crs": "OGC:CRS84",
    "boundary_layer": "admin_level_4",
    "layers": [
      {
        "id": "admin_level_4",
        "source_name": "admin_level_4",
        "name": "Граница Республики Марий Эл",
        "visible": true,
        "role": "BOUNDARY",
        "geometry_type": "Polygon",
        "style": {
          "fill_color": "#00000000",
          "outline_color": "#CC0000",
          "outline_width": 2.5
        }
      }
    ]
  },
  "layers": {
    "admin_level_4": true,
    "water_polygons": false
  },
  "points": [
    {
      "id": "e30e137b-5861-4603-a15d-85fa32408c50",
      "name": "Йошкар-Ола Центр",
      "latitude": 56.6315,
      "longitude": 47.8861,

    }
  ]
}
```

## 3. Детальное описание полей

### 3.1. Корневой объект (Root)
- **`format`** (*string*, обязательно):
  - `"GeoPoint Mapper Project"` — основной формат;
  - `"RME-Mapper Project"` — устаревший формат (поддерживается на чтение).
- **`version`** (*integer*, обязательно): Целочисленная версия структуры формата проекта (текущая: `1`).
- **`map`** (*object*, опционально): Данные о подключенной карте. Если проект пустой, объект содержит значения по умолчанию.
- **`layers`** (*object / dict*, опционально): Состояние видимости слоев: пара `имя_слоя (string) -> видимость (boolean)`.
- **`points`** (*array of objects*, обязательно): Список сохраненных пользовательских географических точек.

---

### 3.2. Объект карты (`map`)
- **`map_id`** (*string*): Идентификатор профиля карты (например, `"mari_el"`).
- **`relative_path`** (*string*): Относительный путь к файлу карты GeoPackage (`.gpkg`).
- **`name`** (*string*): Отображаемое название карты.
- **`source_type`** (*string*): Тип источника данных (`"geopackage"`, в будущем `"geotiff"`).
- **`crs`** (*string | null*): Строка системы координат карты (например, `"OGC:CRS84"`, `"EPSG:4326"`).
- **`boundary_layer`** (*string | null*): Имя слоя, выбранного в качестве административной границы.
- **`layers`** (*array of objects*): Список метаданных и настроек визуализации слоев карты.

---

### 3.3. Объект точки (`points[]`)
Каждая точка хранит координаты в первоисточнике WGS84:
- **`id`** (*string*): Уникальный UUID точки.
- **`name`** (*string*): Пользовательское название точки.
- **`latitude`** (*float*): Широта в десятичных градусах (DD) от -90.0 до +90.0.
- **`longitude`** (*float*): Долгота в десятичных градусах (DD) от -180.0 до +180.0.
- **`source_crs`** (*string*): Исходная система координат ввода (по умолчанию `"OGC:CRS84"`).
- **`visible`** (*boolean*): Флаг видимости маркера и зоны на карте.
- **`symbol`** (*string*): Форма маркера (`"circle"`, `"square"`, `"triangle"`).
- **`size`** (*float*): Размер маркера в пикселях экрана (от 4.0 до 50.0).
- **`red`**, **`green`**, **`blue`** (*integer*): Цветовые компоненты RGB маркера (0..255).
- **`zone_enabled`** (*boolean*): Флаг включения геодезической зоны вокруг точки.
- **`radius_m`** (*float*): Радиус геодезической зоны в метрах (от 1.0 до 1 000 000.0).
- **`zone_red`**, **`zone_green`**, **`zone_blue`** (*integer*): Цветовые компоненты RGB заливки зоны (0..255).
- **`zone_opacity`** (*integer*): Процент непрозрачности заливки зоны (от 0 до 100).

---

## 4. Гарантии совместимости между версиями
- Проекты, созданные в сборках Modern (Win 10/11), Legacy 7 или Legacy XP, являются полностью взаимозаменяемыми.
- При открытии проекта на машине с другой файловой структурой относительные пути (`relative_path`) разрешаются относительно каталога сохраненного `.gpmap`, что обеспечивает переносимость проектов на flash-накопителях и сетевых ресурсах.
