# Экспорт объектов и координат (Stage 22)

Подсистема экспорта географических объектов приложения **GeoPoint Mapper** обеспечивает выгрузку точечных объектов проекта в табличные форматы и геопространственные стандарты: **CSV**, **XLSX**, **TXT** и **GeoJSON**.

---

## 1. Поддерживаемые форматы файлов

| Формат | Расширение | Особенности реализации |
|---|---|---|
| **CSV** | `.csv` | Настраиваемый разделитель (запятая `,`, точка с запятой `;`, табуляция `\t`), кодировка UTF-8 с опциональным BOM (`utf-8-sig`) для корректного открытия в Microsoft Excel, экранирование спецсимволов и переводов строк по стандарту RFC 4180. |
| **Excel** | `.xlsx` | Структурированная книга `openpyxl`, данные на отдельном листе `Objects`, полужирный шрифт заголовков колонок. Поле `object_number` записывается со строковым типом данных (`data_type='s'`), что гарантирует сохранение ведущих нулей (`"0042"` не превращается в `42`). Числовые поля (координаты, радиусы, размеры) сохраняются как числа. |
| **TXT** | `.txt` | Текстовый файл с разделителями (по умолчанию табуляция TSV), удобный для копирования и импорта в сторонние расчетные комплексы. |
| **GeoJSON** | `.geojson` | Полная совместимость со стандартом **RFC 7946**. Экспортируется объект верхнего уровня `FeatureCollection`. В геометрии `Point` координаты строго упорядочены как `[longitude, latitude]` в WGS84. Корневой член `crs` строго исключен в соответствии со спецификацией. Кириллица сохраняется в явном виде (`ensure_ascii=False`). |

## 2. Области экспорта (Scope)

Пользователь может выбрать одну из трех областей экспорта:

1. **Все объекты (All Objects)** — выгружаются все зарегистрированные в проекте точки, независимо от их видимости и принадлежности к группам.
2. **Выделенные объекты (Selected Objects)** — выгружаются только те точки, которые выделены в таблице точек `PointsPanel`. При отсутствии выделения кнопка экспорта блокируется.
3. **Видимые объекты (Visible Objects)** — выгружаются объекты с **эффективной видимостью**:
   $$\text{Visible} = \text{point.visible} \land (\text{group is None} \lor \text{group.visible})$$
   Если точка сама видима, но ее родительская группа скрыта, точка исключается из экспорта видимых объектов. Поисковые и категориальные фильтры в интерфейсе таблицы носят презентационный характер и не влияют на расчет скоупов.

В диалоговом окне отображается динамический счетчик: *"Объектов к экспорту: N"*. Если количество объектов равно 0, кнопка *"Экспортировать..."* блокируется.

## 3. Координаты и проекции

- **Десятичные градусы (DD)**: WGS84 (EPSG:4326 / OGC:CRS84), широта (`latitude`) и долгота (`longitude`), настраиваемая точность от 2 до 9 знаков (по умолчанию 6).
- **Градусы, минуты и секунды (DMS)**: Каноническое представление:
  - Широта: `55°45'20.999" N` (или `S` для отрицательных широт).
  - Долгота: `037°37'04.001" E` (или `W` для отрицательных долгот).
  - С фиксацией 3 знаков в секундах (`SS.SSS"`).
- **Спроецированные координаты (X/Y)**:
  - Преобразование выполняется через `CoordinateService.transform_xy` с флагом `always_xy=True`.
  - $X$ — Easting (Восток, метры), $Y$ — Northing (Север, метры).
  - Целевая система координат выбирается пользователем (по умолчанию `EPSG:3857` или активная CRS проекта).
  - Настраиваемая точность от 0 до 6 знаков (по умолчанию 3 знака).
  - При ошибке проецирования или некорректной CRS поля $X$, $Y$ безопасно заполняются пустыми значениями без сбоя процесса.

## 5. Надежность и атомарность записи

- Запись всегда выполняется во временный файл в целевой директории вида `.{filename}.tmp_{uuid}`.
- Замена существующего файла производится атомарным вызовом `os.replace`.
- При возникновении ошибки записи (диск переполнен, сбой I/O) временный файл удаляется, а исходный файл пользователя остается неповрежденным.
- Экспорт является операцией **строго только для чтения** по отношению к состоянию приложения: флаг модификации проекта (`is_modified`), история отмены/повтора (`UndoManager`) и текущие выборки объектов холста не изменяются.

---

## 6. Производительность и масштабируемость

Потоковая обработка записей обеспечивает высокую скорость экспорта:
- **1 000 точек**: < 0.2 с;
- **10 000 точек**: < 1.0 с;
- **50 000 точек**: < 4.0 с;
- **100 000 точек**: масштабируемая выгрузка без падений и переполнения памяти (OOM).

---

## 7. Обратная совместимость с Мастером импорта

Файлы CSV и XLSX, экспортированные системой, на 100% совместимы со встроенным сервисом `ImportService`:
- Имена колонок (`object_number`, `name`, `category`, `group`, `latitude`, `longitude`, `description`) автоматически распознаются словарем синонимов `CANONICAL_HEADERS`.
- Ведущие нули номеров объектов, параметры зон и оформление считываются без потерь данных.
