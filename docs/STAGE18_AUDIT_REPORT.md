Дублирующие тесты не создавались.

### 2. Модель групп (`ObjectGroup` и `GroupService`)
- Проверена генерация уникальных UUID по умолчанию: `ObjectGroup`.
- Обязательность имени, trim пробелов, ограничение до 200 символов: `validate_group_name`.
- Ограничение описания до 8192 символов, запрет HTML-тегов: `validate_group_description`.
- Регистронезависимая проверка уникальности имени (`case-insensitive`): `find_group_by_name`.
- Флаг `visible=True` по умолчанию.
- Сериализация и десериализация `to_dict()` / `from_dict()`.
- Точки с `group_id=None` интерпретируются как «Без группы» (`Ungrouped`).

### 3. Независимость Категории и Группы (Category != Group)
- Категория (`category`) и группа (`group_id`) — ортогональные независимые сущности.
- Смена группы не изменяет категорию точки.
- Смена категории не изменяет группу точки.
- Протестировано в `test_category_and_group_independence`.

### 4. Членство в группах и транзакции Undo/Redo
- Назначение группы одной точке, группе точек, перемещение A -> B, перемещение в Ungrouped (`None`).
- **Смешанное Undo**: выделение точек из разных групп (Группа A, Группа B, Ungrouped) с последующим перемещением в единую группу C при нажатии Ctrl+Z точно восстанавливает исходную группу для каждого отдельного объекта через словарь `previous_groups` в `AssignPointsToGroupCommand`.

### 5. Безопасное удаление группы (Delete Group)
- Удаление группы **не удаляет точки**. Все участники группы переходят в `group_id = None`.
- По Ctrl+Z (Undo) группа восстанавливается с оригинальным ID, названием, описанием и флагом видимости (`visible=False`), а всем точкам возвращается членство в группе: `DeleteGroupCommand`.

### 6 & 7. Формула видимости и независимость уровней
- Формула эффективной видимости:
  $$\text{EffectiveMarker} = \text{GlobalPoints} \land \text{GroupVisible} \land \text{PointVisible}$$
  $$\text{EffectiveZone} = \text{GlobalZones} \land \text{GroupVisible} \land \text{PointVisible} \land \text{ZoneEnabled} \land (\text{Radius} > 0)$$
- Если `point.visible = True`, а `group.visible = False`: маркер, зона, подпись и ореол скрываются на карте, но `point.visible` остается `True`. После включения видимости группы объекты восстанавливаются.
- Проверена вся матрица комбинаций. Изменение одного уровня видимости не мутирует флаги других уровней.

### 8. Экспорт карты
- Скрытые группы гарантированно исключаются из экспорта карты в PNG/JPEG через параметр `hidden_group_ids` в `MapRenderer`.
- Фильтры таблицы в `PointsPanel` (презентационный уровень) не влияют на экспорт точек карты («All Points»).

### 9. Презентационные фильтры и счетчики
- Проверены все 7 вариантов фильтрации:
  1. Group only
  2. Category only
  3. Search only
  4. Group + Category
  5. Group + Search
  6. Category + Search
  7. Group + Category + Search
- Индикаторы счетчика (`Показано X из Y` и `Всего: Y`) обновляются строго синхронно.

### 10. Стабильные point ID в фильтрованной таблице
- Все операции таблицы (Edit, Delete, Hide, Move Point, Zoom, Copy Coordinates, Move to Group, Change Category) используют `point.id` из `item.data(Qt.ItemDataRole.UserRole)`, а не визуальный индекс строки таблицы.

### 11. Правило выбора объектов группы (Rule A)
- Зафиксировано и задокументировано в `docs/GROUPS.md`: действие «Выбрать объекты группы» выбирает **все реальные точки группы** в модели и таблице, даже если часть из них временно скрыта строкой поиска или фильтром категории.

### 12. Zoom to Group
- Реализован в `MapCanvas.zoom_to_group`.
- Поддерживает географическую СК (EPSG:4326) и спроецированные СК (EPSG:3857, зоны UTM).
- Одиночная точка центрируется с комфортным отступом, множество точек масштабируется по охвату.
- Пустая группа — безопасный no-op.
- Зум к скрытой группе вычисляет охват без изменения флагов видимости.

### 13. Групповой стиль объектов (Group Bulk Style)
- Переиспользует существующий `BulkPointStyleDialog`.
- Исправлена сигнатура `PointController.bulk_edit_style_workflow(points: list[MapPoint] | None = None)` для поддержки групповых точек.
- Изменение стиля оборачивается в одну неделимую команду `BulkEditStyleCommand` (откат в один шаг Ctrl+Z).

### 14. Массовая смена категории (Bulk Category)
- Диалог `ChangeCategoryDialog` позволяет изменить категорию для всех выделенных точек.
- Откат через `BulkChangeCategoryCommand` восстанавливает исходные категории для каждой отдельной точки.

### 15 & 16. Диалог точки и панель свойств
- В `PointDialog` комбобокс группы содержит «Без группы» (`None`) и список групп проекта. Редактирование точки не создает новые группы автоматически.
- В `PropertiesPanel` отображается имя группы или «Без группы». Технический UUID пользователю не показывается.

### 17, 18, 19. Формат проекта, совместимость и безопасность данных
- Формат `.gpmap` сохраняет секцию `"groups"` и атрибут `"group_id"` у точек.
- Старые проекты без `"groups"` (форматов `.gpmap` и legacy `.rmeproject`) загружаются без ошибок: `groups = []`, `point.group_id = None`.
- «Orphan reference»: при ссылке на несуществующий ID точки сбрасываются в `group_id = None` с предупреждением в журнал (`logger.warning`), без падений и потерь точек.

### 20. Критическая проверка: Детерминированное разрешение дубликатов ID групп
- При наличии нескольких групп с одинаковым `id = X`:
  1. Первая встреченная группа **детерминированно сохраняет `id = X`**.
  2. Каждому последующему дубликату генерируется новый уникальный UUID.
  3. Точки с `group_id = X` детерминированно остаются закрепленными за первой группой.
  4. Переименованный ID дубликата не перехватывает чужие точки.
  5. Событие логируется: `duplicate_group_id: группа '%s' имеет дублирующийся ID '%s', сгенерирован новый`.
  6. Логика закреплена в `project_service.py`, задокументирована в `docs/GROUPS.md` и протестирована в `test_duplicate_group_id_with_points_deterministic_assignment`.

### 21, 22, 23. Импорт групп
- Поддержаны колонки групп (`group`, `группа`, `имя_группы`, `название_группы`).
- При совпадении с существующей группой («Forest» и «forest») используется существующая группа (без дублирования).
- При `create_missing_groups=False` точки переходят в Ungrouped.
- Отмена импорта (Ctrl+Z) удаляет импортированные точки и удаляет созданные новые группы, а **существовавшие до импорта группы гарантированно сохраняются**.

### 26. Локализация RU / EN

- Пользовательские названия групп, описания и категории не изменяются при смене языка интерфейса.

## 6. Известные ограничения (Known Limitations)

1. **Одноуровневая структура 1:N**: отсутствует поддержка вложенных подгрупп и множественного членства M:N (сохранена простота и высокая скорость).
2. **Разовое применение стилей (Bulk Style)**: изменение стиля через группу разово обновляет параметры конкретных `MapPoint`, а не является динамическим стилем слоя.
3. **Регистронезависимая уникальность имён**: в рамках проекта имена групп уникальны без учета регистра (нельзя одновременно создать «Лес» и «лес»).
