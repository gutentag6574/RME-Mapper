# Форматы данных

## 1. Ручной ввод

### DD — десятичные градусы

Пример:

```text
56.637556, 47.886306
```

Поля:

- latitude;
- longitude.

### DMS — градусы, минуты, секунды

Пример:

```text
56°38'15.2" N
47°53'10.7" E
```

Поля широты:

- градусы;
- минуты;
- секунды;
- N/S.

Поля долготы:

- градусы;
- минуты;
- секунды;
- E/W.

Нулевые минуты и секунды допустимы.

---

## 2. Правила валидации

### Широта

- градусы: 0–90;
- минуты: 0–59;
- секунды: >= 0 и < 60.

### Долгота

- градусы: 0–180;
- минуты: 0–59;
- секунды: >= 0 и < 60.

### RGB

- R: 0–255;
- G: 0–255;
- B: 0–255.

### Радиус

- число > 0;
- единица: `m` или `km`.

## 3. XLSX — простой формат

Файл:

`test_data/excel/test_coordinates_simple.xlsx`

Столбцы:

| name | latitude | longitude |
|---|---:|---:|
| Point 1 | 56.637556 | 47.886306 |

Обязательные поля:

- latitude;
- longitude.

`name` может быть пустым.

---

## 4. XLSX — DMS

Файл:

`test_data/excel/test_coordinates_dms.xlsx`

| name | lat_deg | lat_min | lat_sec | lat_dir | lon_deg | lon_min | lon_sec | lon_dir |
|---|---:|---:|---:|---|---:|---:|---:|---|
| Point 1 | 56 | 38 | 15.2 | N | 47 | 53 | 10.7 | E |

Допустимый тест:

```text
lat_min = 0
lat_sec = 0
```

---

## 5. Расширенный формат импорта

Планируемые поля:

| Поле | Назначение |
|---|---|
| id | внешний ID |
| name | название точки |
| latitude | широта DD |
| longitude | долгота DD |
| radius | радиус |
| radius_unit | m/km |
| shape | circle/square/triangle |
| r | красный канал |
| g | зеленый канал |
| b | синий канал |
| label | подпись |
| comment | комментарий |

---

## 6. CSV/TXT

Поддерживаемые разделители:

- запятая;
- точка с запятой;
- TAB.

Кодировка по умолчанию: UTF-8.

---

## 7. Ошибочные тестовые данные

Нужно иметь примеры:

- минуты = 60 и больше;
- секунды = 60 и больше;
- широта > 90;
- долгота > 180;
- отсутствующая широта;
- отсутствующая долгота;
- RGB < 0;
- RGB > 255;
- неизвестная форма значка;
- отрицательный радиус;
- текст вместо числа.

Для каждой ошибки программа должна показывать номер строки и понятную причину.
