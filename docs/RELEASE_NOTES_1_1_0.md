# GeoPoint Mapper 1.1.0

Изменения выполнены в исходном проекте на ветке `main`. Версия объединяет
исправления проверенных замечаний аудита и обновление рабочего интерфейса.
Разбор каждого замечания: [AUDIT_RESOLUTION.md](AUDIT_RESOLUTION.md).

## Как открыть изображение с PGW

1. Положите `plan.png` и `plan.pgw` в одну папку с одинаковым основным именем.
   Если есть `plan.prj`, сохраните его рядом.
2. Выберите «Открыть карту» и укажите PNG либо PGW. Поддерживается и
   перетаскивание файла в окно приложения.
3. Проверьте систему координат. PGW задаёт положение и размер пикселей,
   но сам по себе не содержит CRS. При отсутствии корректного PRJ выберите
   систему вручную.
4. Для **WGS 84 / UTM zone 39N** с присланного изображения выберите
   **EPSG:32639**. Координаты вводятся в метрах: X — Easting, Y — Northing.
   Этот код применим, когда исходные координаты действительно заданы в этой CRS.

Если привязки ещё нет, откройте «Карта → Геопривязать изображение»:
укажите CRS, добавьте контрольные точки, проверьте результат и примените.
Для наложения плана поверх другой карты используйте вкладку «Подложки».
Там доступны порядок, видимость и прозрачность; другая CRS преобразуется автоматически.

## Что изменилось для ежедневной работы

- Таблица точек снизу, вкладки слоёв, групп, подложек и треков слева;
  свойства автоматически открываются при выборе точки. Раскладка настраивается в «Вид».
- Светлая, тёмная и системная темы; параметры программы в
  «Настройки → Настройки программы» (`Ctrl+,`).
- Поиск по имени/номеру точки и переход по координатам над картой.
  Для WGS84 порядок — широта, долгота; для CRS карты — X, Y.
- Вставка координат из буфера с выбором CRS и проверкой каждой строки.
- Сохранение пользовательских XYZ/WMS, управление кэшем.
- Импорт GPX/KML/KMZ, сохранение измерений в проект, управление треками и Undo/Redo.
- Сборка проекта вместе с локальными данными в переносимый ZIP.

## Установка

В `release/installer/` находится установщик, в `release/portable/` — Portable ZIP.
Portable нужно полностью распаковать и затем запустить `GeoPointMapper.exe`.
Предыдущая версия 1.0.1 сохранена. Новая обычная сборка использует основной
профиль программы; отдельная предварительная UX-сборка остаётся независимой.

Подробности интерфейса и границы функций:
[UX_IMPLEMENTATION.md](UX_IMPLEMENTATION.md),
[AUDIT_RESOLUTION.md](AUDIT_RESOLUTION.md).
