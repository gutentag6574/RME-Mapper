# Форматы файлов и мастер массового импорта точек

В приложении **GeoPoint Mapper** реализован полнофункциональный пошаговый мастер пакетного импорта пользовательских точек из файлов:
- **XLSX** (Microsoft Excel 2007+)
- **CSV** (текстовые файлы с разделителями-запятыми, точками с запятой или табуляцией)
- **TXT** (текстовые файлы табличного вида)

---

## 1. Мастер импорта (Import Wizard)

Мастер состоит из 5 логических шагов:

1. **Файл / Source**: Выбор исходного файла, отображение расширения и размера (до 50 МБ).
2. **Структура файла / File Structure**:
   - Выбор листа рабочей книги Excel (XLSX);
   - Выбор кодировки (`Авто`, `UTF-8`, `UTF-8 BOM`, `Windows-1251`);
   - Выбор разделителя (`Авто`, `,`, `;`, `\t`);
   - Номер строки заголовков (от 1 до 100);
   - Предпросмотр исходной структуры файла (первые 50 строк) с подсветкой строки заголовков.
3. **Сопоставление колонок / Column Mapping**:
   - Выбор формата координат: Авто, DD, DMS, X/Y (пользовательская СК);
   - Поле ввода и валидация исходной СК (например, `EPSG:3857`);
   - Назначение колонок файла полям приложения с опцией `[ Не использовать ]`;
   - Пресеты сопоставления: сохранение, загрузка и удаление именованных схем;
   - Защита от конфликтов сопоставления.
4. **Проверка данных / Validation & Preview**:
   - Построчная валидация всех строк файла;
   - Интерактивная таблица с колонками: `Строка`, `Статус`, `Название`, `Координаты`, `Проблема`;
   - Фильтры категорий: `Все`, `Корректные`, `Предупреждения`, `Ошибки`;
   - Текстовый поиск по номеру строки, имени точки или описанию ошибки;
   - Политика обработки дубликатов: `Импортировать все` или `Пропустить дубликаты`;
   - Политика выхода за пределы карты: `Импортировать` или `Пропустить`;
   - Панель детального просмотра выбранной строки с исходными сырыми значениями.
5. **Подтверждение / Import Summary**:
   - Итоговая сводка количества импортируемых и пропускаемых строк;
   - Проверка неизменности файла на диске (`mtime` + `size`);
   - Проверка лимита проекта (существующие + новые <= 100 000 точек);
   - Завершение импорта в один шаг с возможностью отмены по `Ctrl+Z`.

## 2. Координатные схемы

### Схема A: Десятичные градусы (DD)

#### Обязательные колонки:
| Каноническое имя | Синонимы (RU / EN) | Допустимые значения | Описание |
|---|---|---|---|
| `latitude` | `lat`, `широта`, `ш`, `y` | Число от `-90.0` до `90.0` | Географическая широта |
| `longitude` | `lon`, `lng`, `долгота`, `д`, `x` | Число от `-180.0` до `180.0` | Географическая долгота |

- **Десятичный разделитель**: Поддерживается как точка (`56.6328`), так и запятая (`56,6328`).

### Схема B: Градусы, минуты, секунды (DMS)

#### Обязательные колонки:
| Каноническое имя | Синонимы (RU / EN) | Диапазон | Описание |
|---|---|---|---|
| `lat_deg` | `градусы_широты`, `град_шир`, `lat_degrees`, `lat_d` | `0 .. 90` (целое число) | Градусы широты |
| `lat_min` | `минуты_широты`, `мин_шир`, `lat_minutes`, `lat_m` | `0 .. 59` (целое число) | Минуты широты |
| `lat_sec` | `секунды_широты`, `сек_шир`, `lat_seconds`, `lat_s` | `0.0 <= sec < 60.0` | Секунды широты (вещественные) |
| `lat_dir` | `направление_широты`, `полушарие_широты`, `lat_direction` | `N`, `S`, `С`, `Ю` | Полушарие широты (север/юг) |
| `lon_deg` | `градусы_долготы`, `град_долг`, `lon_degrees`, `lon_d` | `0 .. 180` (целое число) | Градусы долготы |
| `lon_min` | `минуты_долготы`, `мин_долг`, `lon_minutes`, `lon_m` | `0 .. 59` (целое число) | Минуты долготы |
| `lon_sec` | `секунды_долготы`, `сек_долг`, `lon_seconds`, `lon_s` | `0.0 <= sec < 60.0` | Секунды долготы (вещественные) |
| `lon_dir` | `направление_долготы`, `полушарие_долготы`, `lon_direction` | `E`, `W`, `В`, `З` | Полушарие долготы (восток/запад) |

- **Ограничения геодезии**:
  - При широте 90° минуты и секунды обязаны быть строго `0`.
  - При долготе 180° минуты и секунды обязаны быть строго `0`.
  - Значения 0 минут и 0 секунд допустимы.

### Схема C: Проецированные координаты X/Y (Custom CRS)

#### Обязательные колонки:
| Каноническое имя | Синонимы (RU / EN) | Описание |
|---|---|---|
| `x` | `x_coord`, `easting`, `восток`, `координата_x` | Координата X (Easting) в выбранной СК |
| `y` | `y_coord`, `northing`, `север`, `координата_y` | Координата Y (Northing) в выбранной СК |

- **Исходная СК**: Задается пользователем через валидный идентификатор EPSG (например: `EPSG:3857`, `EPSG:32637`). Проверяется через библиотеку `pyproj`.
- **Порядок осей**: Преобразование всегда выполняется с параметром `always_xy=True`.
- Координаты автоматически преобразуются в WGS 84 (`EPSG:4326`) долготу и широту перед сохранением в проекте.

## 4. Пресеты сопоставления колонок (Presets)

Пользователь может сохранить схему сопоставления под произвольным именем.
- Пресет сохраняет: формат координат, исходную СК (для X/Y), привязку полей к именам столбцов исходного файла.
- Привязка строго привязана к **названиям колонок** (не к номерам позиций).
- Пресеты хранятся локально в настройках пользователя (`AppSettingsService`) и не изменяют исходные файлы.

---

## 5. Политики фильтрации

- **Дубликаты координат**:
  - `Импортировать все`: добавляет все точки, помечая дубликаты предупреждением.
  - `Пропустить дубликаты`: исключает повторные точки (как внутри файла, так и относительно уже существующих точек проекта).
- **Точки вне рабочей области карты**:
  - `Импортировать`: импортирует точки с предупреждением.
  - `Пропустить`: исключает точки вне границ карты из итогового импорта.
- **Ошибочные строки**:
  - Строки с ошибками никогда не импортируются. При этом пользователь всегда может импортировать корректные строки файла.
