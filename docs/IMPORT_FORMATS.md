# Форматы файлов для массового импорта точек

В приложении **GeoPoint Mapper** реализован пакетный импорт пользовательских точек из файлов:
- **XLSX** (Microsoft Excel 2007+)
- **CSV** (текстовые файлы с разделителями-запятыми или точками с запятой)
- **TXT** (текстовые файлы с разделителями-табуляциями или точками с запятой)

---

## 1. Общие принципы

1. **Строка заголовков**: Первая непустая строка файла обязана содержать названия колонок.
2. **Регистронезависимость и синонимы**: Названия колонок сопоставляются без учета регистра, краевых пробелов и подчеркиваний (поддерживаются русские и английские синонимы).
3. **Пустые строки**: Полностью пустые строки автоматически пропускаются и не считаются ошибками.
4. **Безопасность**: Файлы читаются строго read-only. В файлах Excel формулы не вычисляются самостоятельно, макросы и внешние ссылки блокируются.

---

## 2. Координатные схемы

Поддерживаются две канонические схемы координат. Система координат исходных данных по умолчанию трактуется как **WGS 84 (EPSG:4326)**.

### Схема A: Десятичные градусы (DD)

#### Обязательные колонки:
| Каноническое имя | Синонимы (RU / EN) | Допустимые значения | Описание |
|---|---|---|---|
| `latitude` | `lat`, `широта`, `ш`, `y` | Число от `-90.0` до `90.0` | Географическая широта |
| `longitude` | `lon`, `lng`, `долгота`, `д`, `x` | Число от `-180.0` до `180.0` | Географическая долгота |

- **Десятичный разделитель**: Поддерживается как точка (`56.6328`), так и запятая (`56,6328`).
- **Неоднозначность запятой**: В CSV-файлах с разделителем-запятой для чисел с десятичной запятой используйте кавычки (`"56,63","47,88"`) либо используйте точку с запятой в качестве разделителя колонок (`56,63;47,88`).

### Схема B: Градусы, минуты, секунды (DMS)

#### Обязательные колонки:
| Каноническое имя | Синонимы (RU / EN) | Диапазон | Описание |
|---|---|---|---|
| `lat_deg` | `градусы_широты`, `град_шир`, `lat_degrees`, `lat_d` | `0 .. 90` (целое число) | Градусы широты |
| `lat_min` | `минуты_широты`, `мин_шир`, `lat_minutes`, `lat_m` | `0 .. 59` (целое число) | Минуты широты |
| `lat_sec` | `секунды_широты`, `сек_шир`, `lat_seconds`, `lat_s` | `0.0 <= sec < 60.0` | Секунды широты (дробные) |
| `lat_dir` | `направление_широты`, `полушарие_широты`, `lat_direction` | `N`, `S`, `С`, `Ю` | Полушарие широты (север/юг) |
| `lon_deg` | `градусы_долготы`, `град_долг`, `lon_degrees`, `lon_d` | `0 .. 180` (целое число) | Градусы долготы |
| `lon_min` | `минуты_долготы`, `мин_долг`, `lon_minutes`, `lon_m` | `0 .. 59` (целое число) | Минуты долготы |
| `lon_sec` | `секунды_долготы`, `сек_долг`, `lon_seconds`, `lon_s` | `0.0 <= sec < 60.0` | Секунды долготы (дробные) |
| `lon_dir` | `направление_долготы`, `полушарие_долготы`, `lon_direction` | `E`, `W`, `В`, `З` | Полушарие долготы (восток/запад) |

- **Ограничения геодезии**:
  - При широте 90° минуты и секунды обязаны быть строго `0`.
  - При долготе 180° минуты и секунды обязаны быть строго `0`.
  - `0` минут и `0` секунд допустимы. Пустые значения минут или секунд не превращаются в 0 автоматически и вызывают ошибку строки.

## 3. Необязательные колонки

### Название точки:
| Поле | Синонимы | Описание |
|---|---|---|
| `name` | `название`, `имя`, `point_name`, `метка`, `label`, `title` | Имя точки (до 500 символов). Если отсутствует — генерируется автоматически: `Точка N`. |

### Параметры стиля маркера:
| Поле | Синонимы | Значения по умолчанию | Допустимые значения |
|---|---|---|---|
| `symbol` | `форма`, `тип_маркера`, `shape` | `circle` | `circle` (`круг`), `square` (`квадрат`), `triangle` (`треугольник`) |
| `size` | `размер`, `marker_size` | `12.0` | Вещественное число от `4.0` до `50.0` px |
| `red` | `r`, `красный` | `220` | Целое число `0 .. 255` |
| `green` | `g`, `зеленый` | `30` | Целое число `0 .. 255` |
| `blue` | `b`, `синий` | `30` | Целое число `0 .. 255` |

> [!WARNING]
> Если задан цвет маркера RGB, должны быть указаны все 3 компонента (`red`, `green`, `blue`). Неполное задание цвета считается ошибкой строки.

### Параметры геодезической зоны:
| Поле | Синонимы | Значения по умолчанию | Допустимые значения |
|---|---|---|---|
| `zone_enabled` | `zone`, `зона`, `геозона` | `false` | `true`/`false`, `1`/`0`, `yes`/`no`, `да`/`нет` |
| `radius` | `радиус`, `zone_radius` | `0.0` | Число от `1.0` до `1 000 000.0` м при включенной зоне |
| `radius_unit` | `единица_радиуса`, `ед_изм` | `m` | `m`, `м` (метры); `km`, `км` (километры) |
| `zone_red` | `zone_r`, `цвет_зоны_r` | `220` | Целое число `0 .. 255` |
| `zone_green` | `zone_g`, `цвет_зоны_g` | `30` | Целое число `0 .. 255` |
| `zone_blue` | `zone_b`, `цвет_зоны_b` | `30` | Целое число `0 .. 255` |
| `zone_opacity` | `opacity`, `прозрачность` | `30` | Целое число от `0` до `100` % |

## 4. Разделители и кодировки

### Разделители:
- Запятая (`,`);
- Точка с запятой (`;`);
- Табуляция (`\t`).

Автоопределение выбирает разделитель на основе анализа строки заголовков.

### Кодировки:
- `UTF-8` (с сигнатурой BOM и без BOM);
- `Windows-1251` (`CP1251`) — автоматический fallback для файлов из старых версий Windows.

## 5. Примеры файлов

### Пример 1: CSV в формате десятичных градусов (DD)
```csv
name;latitude;longitude;symbol;size;radius;radius_unit
Йошкар-Ола;56.6328;47.8844;circle;14;10;km
Волжск;55.8694;48.3589;square;12;8000;m
Козьмодемьянск;56.3422;46.5658;triangle;12;0;m
```

### Пример 2: CSV в формате градусов, минут, секунд (DMS)
```csv
name;lat_deg;lat_min;lat_sec;lat_dir;lon_deg;lon_min;lon_sec;lon_dir
Точка Север;56;37;58.08;N;47;53;3.84;E
Точка Экватор;0;0;0.0;N;45;0;0.0;E
Остров Пасхи;27;7;0.0;S;109;22;0.0;W
```

### Пример 3: TXT с разделителями-табуляциями (TSV)
```tsv
name	latitude	longitude
Пункт 1	56.632800	47.884400
Пункт 2	56.700000	47.950000
```

## 6. Типичные ошибки валидации

| Ситуация | Поведение валидатора |
|---|---|
| Строка содержит имя, но пустые координаты | Строка отмечается как ошибочная (`import.err.missing_coordinates`). |
| Широта > 90° или < -90° | Ошибка диапазона (`import.err.lat_out_of_range`). |
| Минуты или секунды >= 60 | Ошибка диапазона DMS (`import.err.lat_min_range`, `import.err.lat_sec_range`). |
| 90° широты с ненулевыми минутами/секундами | Ошибка полярной координаты (`import.err.lat_90_nonzero`). |
| Указан `red`, но не указан `blue` | Ошибка неполного цвета (`import.err.incomplete_rgb`). |
| Зона включена, но радиус 0 или пуст | Ошибка радиуса (`import.err.radius_required_when_zone_enabled`). |
| Дубликат координат с другой строкой файла | Точка остается валидной, выводится предупреждение (`import.warn.duplicate_coordinates`). |
| Координата лежит вне полигона карты | Точка остается валидной, выводится предупреждение (`import.warn.outside_working_area`). |
