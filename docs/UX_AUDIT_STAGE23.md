# UX/UI-аудит перед финальным этапом

**Дата:** 21 сентября 2026  
**Статус:** выполнен как рабочий аудит в рамках Stage 23.

## Решения

Основной сценарий пользователя: открыть карту или проект → добавить либо импортировать объекты → проверить их на карте → экспортировать результат. Панель быстрых действий должна поддерживать именно этот путь; редкие режимы не должны конкурировать с ним.

### Изменения

1. Устранён конфликт `Ctrl+M`: он открывает карту; перенос точки теперь вызывается через `Ctrl+Shift+V`.
2. Измерение расстояния получило документированную горячую клавишу `Ctrl+Shift+M`; измерение площади — `Ctrl+Shift+G`.
3. Верхняя панель сокращена до частых операций: открыть карту, открыть проект, сохранить, отменить/повторить, добавить точку и показать всю карту. Режимы добавления кликом, перемещения и измерений остаются доступными в тематических меню и не перегружают рабочее пространство.

## Проверочный список перед Stage 27

- Пройти сценарии с пустым проектом, картой без точек, большим набором точек и офлайн-режимом.
- Проверить интерфейс при масштабировании Windows 100%, 125% и 150%, а также при ширине окна 1280 px.
- Сверить все команды меню с их shortcut и tooltip; у двух доступных действий не должно быть одинаковой комбинации.
- Провести живое тестирование минимум с двумя пользователями, которые не участвовали в разработке, и зафиксировать места, где они останавливаются или ошибаются.
