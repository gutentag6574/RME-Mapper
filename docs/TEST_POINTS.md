# Контрольные точки проекта

## Назначение

Контрольные точки используются для проверки того, что программа преобразует и отображает координаты точно так же, как QGIS.

Минимум: 5 точек.

Рекомендуется: 10–20 точек.

Для первого набора желательно выбрать точки в разных частях карты:

- север;
- юг;
- запад;
- восток;
- центр.

## Критерий завершения

Координатный модуль нельзя считать готовым, пока контрольные точки не совпадают с эталонными значениями QGIS в пределах согласованной допустимой погрешности.
