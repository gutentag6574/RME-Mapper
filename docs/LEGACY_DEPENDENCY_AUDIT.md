# Аудит зависимостей GeoPoint Mapper для Legacy-платформ

В данном документе приводится подробный аудит библиотек и зависимостей проекта GeoPoint Mapper (`pyproject.toml`, `requirements.txt`) с оценкой их применимости для будущих сборок под **Windows 7** и **Windows XP**.

## Детальный анализ ключевых компонентов

### 1. PySide6 (GUI)
- **Текущее использование**: Все диалоги, панели, виджеты и графический холст `MapCanvas` построены на базе PySide6 (модули `QtCore`, `QtGui`, `QtWidgets`).
- **Блокер для Windows 7**: Компания The Qt Company официально прекратила поддержку Windows 7, начиная с Qt 6.0. Бинарные DLL Qt6 используют функции Windows API (например, `GetDpiForWindow`, современные механизмы DirectX), которых нет в `user32.dll` / `kernel32.dll` Windows 7.
- **Блокер для Windows XP**: Полная несовместимость.
- **Стратегия для Legacy**:
  - Сохранение модулей Core полностью независимыми от PySide6.
  - Создание GUI-адаптера или отдельного слоя представления на базе **PyQt5** (для Windows 7) и **PyQt4** / **PySide 1.2** (для Windows XP).

### 2. GeoPandas & pyogrio (Чтение векторных карт)
- **Текущее использование**: Считывание слоев GeoPackage в структуры `GeoDataFrame`, получение CRS и охвата (bounds).
- **Блокер для Windows XP**: GeoPandas тянет за собой массивный граф C-расширений: `numpy`, `pandas`, `pyproj`, `shapely`, `pyogrio` (GDAL). Ни один из этих пакетов в актуальных версиях не имеет колес (wheels) для Windows XP и компилятора MSVC 2010.
- **Стратегия для Legacy**:
  - Файлы GeoPackage (`*.gpkg`) по стандарту OGC являются обычными базами данных SQLite 3.
  - Стандартная библиотека Python (`sqlite3`) присутствует во всех версиях Python, включая Python 3.4 на Windows XP.
  - Для Legacy XP чтение слоев и геометрических объектов реализуется через `sqlite3` прямыми SQL-запросами к таблицам `gpkg_contents`, `gpkg_geometry_columns` и парсинг бинарных заголовков геометрии GeoPackage.

### 3. pyproj (Геодезические вычисления и CRS)
- **Текущее использование**: Сервис `GeodesicService` использует `pyproj.Geod(ellps="WGS84")` для построения геодезических кругов с учетом кривизны Земли. Модуль `coordinate_service.py` использует `pyproj.Transformer` для проекций.
- **Блокер для Windows XP**: Современный pyproj требует библиотеку PROJ 9+, использующую C++17 и новейшие системные вызовы.
- **Стратегия для Legacy**:
  - Для WGS84 расчет геодезического круга (прямая геодезическая задача) легко выражается аналитическими формулами Карни / Винсенти на чистом Python (модуль `math`).
  - Преобразования стандартных проекций (Гаусс-Крюгер, UTM) могут быть реализованы на чистом Python через формулы проекций без внешних зависимостей.

### 4. Shapely (Операции с геометрией)
- **Текущее использование**: Создание полигонов `Polygon`, точек `Point` и проверка пересечений.
- **Блокер для Windows XP**: Библиотека GEOS C++, на которой базируется Shapely, не собирается под платформы старше Windows 7.
- **Стратегия для Legacy**:
  - Базовые операции (хранение списка вершин полигона, нахождение `bounding_box`, алгоритм Ray Casting для проверки попадания точки в полигон) реализуются стандартными методами Python.
