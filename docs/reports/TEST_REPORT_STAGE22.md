## 1. Резюме (Executive Summary)

В рамках Этапа 22 в приложении **GeoPoint Mapper** полностью реализована и протестирована подсистема экспорта географических объектов и их атрибутов в табличные и GIS-совместимые форматы.

* **Поддерживаемые форматы:** CSV, XLSX, TXT, GeoJSON.
* **Поддерживаемые области (Scopes):**
  - **All Objects (Все объекты)**;
  - **Selected Objects (Выделенные объекты)**;
  - **Visible Objects (Видимые объекты)** с учетом эффективной видимости ($\text{point.visible} \land (\text{group is None} \lor \text{group.visible})$).
* **Координатные представления:**
  - Десятичные градусы WGS84 (DD, настраиваемая точность 2..9 знаков);
  - Градусы, минуты, секунды (канонический DMS `DD°MM'SS.SSS" N/S`, `DDD°MM'SS.SSS" E/W`);
  - Спроецированные координаты (X/Y) в выбранной целевой CRS через `CoordinateService` (`always_xy=True`).
* **Атомарность и безопасность:** Все файлы записываются через временный файл и атомарный вызов `os.replace`. При любых сбоях диск не засоряется, исходные файлы не повреждаются.
* **Чистота состояния (State Purity):** Экспорт не меняет `project.is_modified`, историю Undo/Redo и текущие выделения объектов.
* **Результаты тестов:**
  - Новых модульных и контрольных тестов: **46 passed** (23 модульных + 23 контрольных);
  - Общий регрессионный сьют проекта: **1135 passed**, 97 warnings (0 новых), **0 RuntimeWarning**.
  - Сквозной GUI smoke check: **PASS**.

## 2. Архитектурные компоненты

1. **`src/rme_mapper/models/object_export.py`**:
   - Енумы `ObjectExportFormat` (CSV, XLSX, TXT, GEOJSON), `ObjectExportScope` (ALL, SELECTED, VISIBLE), `CsvDelimiter` (COMMA, SEMICOLON, TAB).
   - Класс спецификации поля `ExportFieldDefinition`.
   - Реестр полей `EXPORT_FIELDS` (27 полей) и словарь быстрого доступа `EXPORT_FIELDS_BY_KEY`.
   - Датакласс параметров `ObjectExportOptions`.
2. **`src/rme_mapper/services/object_export_service.py`**:
   - `filter_points`: фильтрация по скоупам с корректным учетом родительской группы.
   - `build_export_record`: построение словаря нормализованных атрибутов точки.
   - `format_lat_dms` и `format_lon_dms`: форматирование DMS.
   - `_export_delimited`: экспорт CSV и TXT с поддержкой BOM, разделителей и экранирования.
   - `_export_xlsx`: экспорт в Excel с отдельным листом `Objects`, жирными заголовками и строковым типом ячейки для защиты ведущих нулей.
   - `_export_geojson`: генерация валидного FeatureCollection по стандарту RFC 7946.
   - Атомарная запись через `.tmp` и `os.replace`.
3. **`src/rme_mapper/ui/export_objects_dialog.py`**:
   - Компактный модальный диалог настройки экспорта.
   - Динамический счетчик объектов (*"Объектов к экспорту: N"*).
   - Автоматическая блокировка кнопки экспорта при 0 объектов.
   - Синхронизация расширения файла при смене формата.
   - Блок опций формата (разделитель, BOM, заголовки).
   - Контроль перезаписи существующих файлов с подтверждением пользователя.
4. **`src/rme_mapper/ui/controllers/export_controller.py`**:
   - Метод `open_export_objects_dialog()`, координирующий вызов диалога, запуск сервиса экспорта и вывод статусных сообщений.
5. **`src/rme_mapper/ui/main_window.py`**:
   - Действие `self.export_objects_action` в меню `self.export_menu` (*"Экспорт"*).
   - Динамическое включение/отключение действия в зависимости от наличия точек (`total > 0`).
   - Полная поддержка динамической локализации RU/EN.
6. **`src/rme_mapper/services/app_settings_service.py`**:
   - Сохранение и восстановление настроек последнего экспорта (формат, скоуп, выбранные поля, CRS, точность, разделитель, BOM, директория).
