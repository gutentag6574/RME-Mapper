# Расширенная модель объектов, стилизация и интерактивное управление (Этап 17)

## 1. Введение
В рамках Этапа 17 картографическая система **GeoPoint Mapper** получила расширенную объектную модель, усовершенствованную стилизацию маркеров и геодезических зон, интерактивное перемещение объектов мышью по холсту карты, пообъектное управление видимостью, адаптивное размещение подписей с защитой от коллизий и обновленный диалог создания/редактирования объектов.

---

## 2. Расширенная модель объекта (`MapPoint`)

Каждый объект на карте описывается сущностью `MapPoint` со следующими новыми атрибутами:

| Поле | Тип | Описание | Ограничения и умолчания |
|---|---|---|---|
| `id` | `str` (UUID) | Внутренний уникальный идентификатор системы | Неизменяемый системный ID |
| `name` | `str` | Название объекта | До 500 символов |
| `object_number` | `str` | Пользовательский номер / шифр объекта | До 100 символов, опционально, по умолчанию `""` |
| `category` | `str` | Категория объекта (для фильтрации и группировки) | До 200 символов, опционально, по умолчанию `""` |
| `description` | `str` | Развернутое описание / примечания | Многострочный текст до 8192 символов, по умолчанию `""` |
| `visible` | `bool` | Индивидуальная видимость объекта на карте | По умолчанию `True` |

### Разделение `id` и `object_number`
- Системный `id` генерируется автоматически (UUID v4) и используется для внутренней адресации, графических элементов и транзакций Undo/Redo.
- `object_number` — это прикладной инвентарный или учетный номер объекта (например: `№ 42-А`, `СКВ-102`), задаваемый пользователем. При отображении в таблице и подписях используется `object_number`. Если он не задан, интерфейс отображает порядковый номер строки, не раскрывая технический UUID.

## 3. Стилизация маркеров и геодезических зон

### 3.1 Оформление маркера (`PointStyle`)
- **Форма**: `circle` (круг), `square` (квадрат), `triangle` (треугольник).
- **Размер**: `4.0 .. 50.0` px (по умолчанию 12 px).
- **Цвет заливки**: RGB (`0 .. 255`).
- **Непрозрачность маркера**: `0 .. 100` % (по умолчанию 100%).
- **Обводка маркера**:
  - Цвет: RGB (`stroke_red`, `stroke_green`, `stroke_blue`, по умолчанию `255, 255, 255`).
  - Толщина: `0.0 .. 10.0` px (`stroke_width`, по умолчанию 1.5 px).

### 3.2 Оформление геодезической зоны (`ZoneStyle`)
- **Радиус**: от `1.0` м до `1 000 000.0` м (1000 км).
- **Цвет заливки**: RGB (`zone_red`, `zone_green`, `zone_blue`).
- **Прозрачность заливки**: `0 .. 100` % (по умолчанию 30%).
- **Граница зоны**:
  - Цвет границы: RGB (`zone_border_red`, `zone_border_green`, `zone_border_blue`, по умолчанию `30, 58, 138`).
  - Толщина границы: `0.0 .. 10.0` px (`zone_border_width`, по умолчанию 1.5 px).
  - Стиль линии границы: `solid` (сплошная), `dash` (штриховая), `dot` (точечная).

> [!NOTE]
> Математический расчет геодезических зон выполняется на эллипсоиде WGS 84 через геодезическую службу `GeodesicService.create_geodesic_circle` (64 сегмента), что гарантирует отсутствие искажений в любых картографических проекциях.

## 4. Интерактивное перемещение объектов мышью

### 4.1 Режим `move_point`
1. Режим активируется через панель инструментов, главное меню или контекстное меню точки.
2. При наведении на маркер точки курсор меняется на `PointingHandCursor` или `CrossCursor`.
3. Зажатие ЛКМ начинает операцию перетаскивания (Drag-and-Drop) с отрисовкой живого перемещения маркера и связанной подписи.
4. Отпускание ЛКМ завершает перемещение:
   - Координаты сцены трансформируются в систему координат карты и затем в `OGC:CRS84` (WGS 84).
   - Выполняется единая транзакция в стеке Undo/Redo: команда `MovePointCommand`.
5. Клавиша **Escape** отменяет текущее перетаскивание, возвращая маркер на исходную позицию без фиксации в стеке Undo/Redo.
6. Перетаскивание пустого пространства карты сохраняет функцию панорамирования (Pan).

## 5. Подписи точек и предотвращение наложений (Collision Avoidance)

### 5.1 Режимы содержимого подписей
Режим выбирается в меню «Вид» -> «Содержимое подписей»:
1. **Только название (`name`)**: отображается значение `point.name`.
2. **Только номер объекта (`number`)**: отображается `point.object_number`. Если номер пуст, подпись не отображается.
3. **Номер и название (`number_name`)**: отображается формат `"<номер> - <название>"`. При отсутствии одного из полей подпись аккуратно выводит доступное поле без висячих разделителей (`" - "`).

### 5.2 Алгоритм предотвращения наложений (4-Candidate Layout)
При отображении подписей на холсте для каждой точки вычисляются 4 кандидата расположения относительно центра маркера:
1. **Upper-Right (UR)** — верхний правый квадрант (приоритетный).
2. **Lower-Right (LR)** — нижний правый квадрант.
3. **Upper-Left (UL)** — верхний левый квадрант.
4. **Lower-Left (LL)** — нижний левый квадрант.

Размеры подписи определяются в экранных пикселях с помощью `QFontMetrics`. Выделенные пользователем точки обрабатываются в первую очередь. Если все 4 квадранта заняты соседними подписями, выбирается кандидат по умолчанию (UR).

## 6. Интерфейс пользователя

- **PointDialog**: реорганизован в трехвкладочный интерфейс `QTabWidget`:
  1. *Основное*: Название, Номер объекта, Категория (с выпадающим списком истории категорий проекта), Описание.
  2. *Координаты*: DD / DMS с двусторонней синхронизацией.
  3. *Оформление*: Стиль маркера (форма, размер, заливка, обводка, непрозрачность) и геодезическая зона (радиус, заливка, граница, стиль). Интерактивное превью маркера.
- **BulkPointStyleDialog**: групповая настройка обводки маркера, непрозрачности и границы зон в одной Undo-транзакции.
- **PropertiesPanel**: форматированное отображение номера объекта, категории, описания, обводки, прозрачности и стиля границы.
- **PointsPanel**: строгое сохранение 6 колонок таблицы, расширенный мгновенный поиск по названию, номеру объекта, категории и описанию. Скрытые объекты отображаются приглушенным серым цветом.
- **MapRenderer**: экспорт в PNG/JPEG с корректным учетом обводки, прозрачности маркеров, стилей границ геозон и режимов подписей. Скрытые объекты не включаются в экспорт.
