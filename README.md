# GeoPoint Mapper

**GeoPoint Mapper** — универсальное настольное приложение для нанесения географических координат и зон заданного радиуса на геопривязанные карты.

Карта Республики Марий Эл входит в состав репозитория в качестве демонстрационного набора данных и тестового профиля для автоматических тестов и проверки координатных систем (CRS). Приложение поддерживает прямое открытие произвольных векторных карт в формате GeoPackage (`*.gpkg`).

## Основные возможности

- **Пустой старт**: чистый запуск приложения без принудительной загрузки карты.
- **Универсальная загрузка карт**: открытие зарегистрированных профилей или произвольных файлов GeoPackage (`*.gpkg`).
- **Инспекция слоев**: выбор слоев для визуализации, отображение геометрии, количества объектов и CRS.
- **Опциональная рабочая граница**: назначение полигонального слоя в качестве границы карты либо работа без нее.
- **Ввод координат**: поддержка десятичных градусов (DD) и градусов/минут/секунд (DMS: N/S, E/W).
- **Стилизация маркеров**: выбор формы (круг, квадрат, треугольник), размера и цвета RGB.
- **Геодезические зоны радиуса**: расчет эллипсоидальных зон вокруг точек по WGS84 через `pyproj.Geod` с настраиваемым цветом и прозрачностью.
- **Проекты**: сохранение и открытие проектов в формате `.gpmap` с поддержкой обратной совместимости с `.rmeproject`.

## Требования

- Python 3.12+
- Windows 10/11
- Зависимости: PySide6, pyproj, geopandas, shapely, pandas, pyogrio, pytest

## Установка и настройка

1. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   ```

2. Активируйте виртуальное окружение:
   - В PowerShell:
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```
   - В CMD:
     ```cmd
     .\.venv\Scripts\activate.bat
     ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   Либо в режиме разработки:
   ```bash
   pip install -e ".[dev]"
   ```

## Запуск приложения

Из корневой папки проекта:

```powershell
.\.venv\Scripts\python.exe -m rme_mapper.main
```

## Запуск тестов

Для запуска тестов используйте `pytest`:

```powershell
.\.venv\Scripts\pytest
```

## Структура проекта

```text
src/
└── rme_mapper/
    ├── __init__.py          # Инициализация пакета и PROJ/GDAL
    ├── main.py              # Точка входа в приложение GeoPoint Mapper
    ├── ui/                  # Пользовательский интерфейс (PySide6)
    │   ├── __init__.py
    │   ├── main_window.py   # Главное окно GeoPoint Mapper
    │   ├── open_map_dialog.py # Диалог открытия карты и выбора слоев GeoPackage
    │   └── add_point_dialog.py # Диалог создания/редактирования точек и зон
    ├── models/              # Модели данных (MapPoint, MapLayer, MapProfile, ProjectData)
    ├── maps/                # MapCanvas и конфигурация путей
    ├── coordinates/         # Парсинг и валидация координат DD/DMS
    └── services/            # Сервисы расчетов, слоев, каталога и проектов
maps/
└── test_map/                # Тестовый профиль Республики Марий Эл
tests/                       # Набор автоматических тестов
```
