# Как выбрать первую тестовую карту

Для первого прототипа нужно выбрать только ОДНУ карту.

## Хороший вариант

Лучше всего подходит карта, которая:

- уже использовалась вами в QGIS;
- отображается правильно;
- имеет известную геопривязку;
- имеет CRS;
- охватывает значительную часть Республики Марий Эл;
- содержит узнаваемые объекты для визуальной проверки;
- доступна в GeoTIFF или другом геопривязанном растровом формате.

## Приоритет форматов

1. GeoTIFF (`.tif`, `.tiff`) с корректной геопривязкой.
2. Растр + world file (`.jpg + .jgw`, `.png + .pgw` и т. п.).
3. Обычный PNG/JPG, который уже привязан в QGIS и может быть экспортирован в GeoTIFF.
4. Непривязанный скан — только если других вариантов нет.

## Пока НЕ выбирать

На первом этапе желательно не использовать карту:

- с неизвестной системой координат;
- с сомнительной привязкой;
- собранную из нескольких листов;
- сильно искаженную;
- требующую сложной ручной трансформации;
- если неизвестно, где на ней должны находиться реальные координаты.

Такие карты можно добавить позже после успешного прототипа.

## Что считается идеальным результатом

В `source/` лежит один исходный файл, например:

```text
source/rme_test_map.tif
```

Он открывается в QGIS, и для него известны:

```text
CRS
EPSG или WKT
Extent
Размер растра
5+ контрольных точек
```

После этого можно переходить к созданию первого GIS-модуля программы.
