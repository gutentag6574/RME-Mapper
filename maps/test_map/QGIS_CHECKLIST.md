# QGIS CHECKLIST — первая тестовая карта

Пройти этот список после того, как карта помещена в `source/`.

---

## 1. Открытие карты

- [ ] Открыт файл именно из `maps/test_map/source/`
- [ ] Карта отображается без ошибок
- [ ] Карта не перевернута
- [ ] Масштаб и геометрия выглядят нормально

Записать имя файла:

```text
Имя файла:
```

---

## 2. CRS слоя

Открыть свойства слоя в QGIS и записать:

```text
Название CRS:

EPSG:

Единицы:

Пользовательская CRS: да / нет
```

Если EPSG отсутствует — это допустимо.

Тогда особенно важно сохранить WKT и/или PROJ.

- [ ] Название CRS сохранено
- [ ] EPSG сохранен, если существует
- [ ] WKT сохранен
- [ ] PROJ сохранен, если доступен
- [ ] Единицы измерения определены

Продублировать эти сведения в:

```text
docs/CRS_INFO.md
```

---

## 3. CRS проекта QGIS

Отдельно проверить CRS самого проекта QGIS.

Он может отличаться от CRS слоя.

Записать:

```text
Название CRS проекта:

EPSG проекта:

Совпадает с CRS карты: да / нет
```

- [ ] CRS проекта определен
- [ ] Проверено, совпадает ли он с CRS слоя

---

## 4. Географическая привязка

Проверить свойства растра.

Нужно определить:

```text
Размер растра:
Ширина (px):
Высота (px):

Extent:
X min:
Y min:
X max:
Y max:
```

- [ ] Размер изображения записан
- [ ] Extent записан
- [ ] Карта имеет геопривязку

Если геопривязки нет:

```text
СТОП: карту пока не использовать как основную тестовую.
Сначала выполнить привязку в QGIS и сохранить подготовленную версию в prepared/.
```

---

## 5. Сопутствующие файлы

Проверить, существуют ли рядом:

```text
.tfw
.jgw
.pgw
.wld
.prj
.aux.xml
```

Если существуют, скопировать их вместе с оригиналом в `source/`.

- [ ] Все сопутствующие файлы сохранены

---

## 6. Скриншоты

Сохранить в `preview/`:

- [ ] `map_overview.png` — общий вид карты
- [ ] `map_qgis.png` — карта в QGIS
- [ ] `crs_layer.png` — окно CRS слоя
- [ ] `crs_project.png` — CRS проекта

Позже:

- [ ] `control_points.png` — карта с контрольными точками

---

## 7. Контрольные точки

Подготовить минимум 5 точек:

- [ ] север
- [ ] юг
- [ ] запад
- [ ] восток
- [ ] центр

Для каждой точки желательно получить:

```text
Исходная широта
Исходная долгота
Исходный CRS

X в CRS карты
Y в CRS карты
```

Все точки занести в:

```text
docs/TEST_POINTS.md
test_data/coordinates/control_points.csv
```

---

## 8. Проверка исходной системы координат точек

Не считать автоматически, что широта/долгота = WGS84.

Нужно подтвердить источник координат.

Записать:

```text
CRS исходных пользовательских координат:
EPSG:
Источник подтверждения:
```

- [ ] Исходный CRS подтвержден
- [ ] Или явно отмечено, что он пока неизвестен

---

## 9. metadata.json

После сбора сведений заполнить:

```text
maps/test_map/metadata.json
```

Особенно важны:

- `source_file`
- `raster.format`
- `raster.width_px`
- `raster.height_px`
- `crs.layer_crs_name`
- `crs.epsg`
- `crs.wkt`
- `crs.proj`
- `crs.units`
- `extent`
- `qgis_reference`

После заполнения заменить:

```json
"status": "TO_FILL"
```

на:

```json
"status": "READY_FOR_PROTOTYPE"
```
