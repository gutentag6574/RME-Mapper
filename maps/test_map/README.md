# Тестовая карта проекта RME Mapper

Эта папка содержит первую карту, на которой проверяется весь базовый GIS-механизм программы.

## Назначение

Первая тестовая карта нужна для проверки:

- открытия растровой карты;
- чтения географической привязки;
- определения CRS;
- преобразования широты/долготы в координаты карты;
- преобразования координат карты в пиксели;
- правильного отображения контрольных точек;
- сравнения результата с QGIS.

До успешной проверки одной карты не следует подключать остальные карты.

## Структура

```text
test_map/
├── README.md
├── metadata.json
├── QGIS_CHECKLIST.md
├── source/
│   └── оригинальные файлы карты
├── prepared/
│   └── подготовленные/перепроецированные версии
└── preview/
    └── скриншоты и превью
```

## Правило для source/

В `source/` кладутся оригинальные файлы без изменений.

Не редактировать и не перезаписывать оригинал.

Если карта состоит из нескольких связанных файлов, нужно сохранить их вместе.

Примеры:

```text
map.tif
map.tif.aux.xml
```

или:

```text
map.jpg
map.jgw
map.prj
```

## Правило для prepared/

В `prepared/` складываются только производные файлы:

- GeoTIFF после обработки;
- перепроецированная карта;
- обрезанная тестовая версия;
- карта с исправленной геопривязкой;
- оптимизированная версия.

Оригинал из `source/` при этом сохраняется.

## Правило для preview/

В `preview/` можно положить:

- скриншот карты из QGIS;
- общий вид карты;
- карту с контрольными точками;
- изображения для будущего окна выбора карт.

Рекомендуемые имена:

```text
map_overview.png
map_qgis.png
control_points.png
thumbnail.png
```

## Что нужно сделать сейчас

1. Выбрать одну карту для первого прототипа.
2. Скопировать оригинал в `source/`.
3. Открыть именно этот файл в QGIS.
4. Заполнить `metadata.json`.
5. Пройти `QGIS_CHECKLIST.md`.
6. Сохранить скриншоты в `preview/`.
7. Информацию о CRS продублировать в `docs/CRS_INFO.md`.

## Критерий готовности

Папка считается подготовленной, когда:

- карта физически находится в `source/`;
- карта открывается в QGIS;
- известен CRS слоя;
- известен CRS проекта;
- сохранен EPSG или WKT/PROJ;
- известны единицы координат;
- есть хотя бы один скриншот карты;
- есть минимум 5 контрольных точек в проекте.
